# Security Policy

Este projeto é destinado exclusivamente a testes autorizados de segurança.

- Não execute testes fora do escopo formal de um programa.
- Não faça DoS, phishing, engenharia social, destruição, persistência ou extração desnecessária de dados.
- Use prova mínima e interrompa ao confirmar o impacto.
- Nunca envie tokens, senhas ou chaves para o Git.
- Revise manualmente todo relatório antes da submissão.

A versão entregue opera em modo de demonstração segura e não executa exploração real.
