# Publicar pelo iPhone usando Render

1. Envie todos os arquivos deste projeto ao repositório GitHub.
2. Acesse o Render e entre com o GitHub.
3. Crie um **Blueprint** e selecione o repositório.
4. O Render reconhecerá o arquivo `render.yaml`.
5. Mantenha `SAFE_DEMO_MODE=true` para o primeiro teste.
6. Adicione chaves apenas no painel de variáveis do Render; nunca em arquivos do projeto.
7. Aguarde o deploy e abra a URL pública fornecida.
